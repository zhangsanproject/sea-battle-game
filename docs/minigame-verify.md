# 抖音小游戏上机验证清单

这份清单只解决一个问题：**`minigame-dist/` 到底能不能在抖音里跑起来。**

现在能证明的只有三件事：构建通过、产物在模拟运行时能加载、逻辑测试通过。**没有一件事能证明它在真机上能玩。** 下面每一项都要在开发者工具或真机上实际看到结果才能打勾；没跑过的项就写「未验证」，不要按经验推断。

## 前置

1. 拿到自己的小游戏 AppID，替换 `minigame/project.config.json` 里的 `appid`。
2. `npm run build:minigame`
3. 确认 `minigame-dist/` 里**只有三个文件**：`game.js`、`game.json`、`project.config.json`。
4. 开发者工具「导入项目」，目录选 `minigame-dist/`，项目类型选「小游戏」。

### 导入的目录必须是干净的

开发者工具会把它扫到的**每一个 `.js`** 都拿去编译，包括不是我们写的那些。

实际踩过的坑：`__MACOSX/template/_game.js` 报 `SyntaxError: Unexpected character 'u{5}'`。那不是代码错误——是 macOS 打 zip 时留下的 AppleDouble 元数据（文件头 `00 05 16 07`，内容是 `Mac OS X`、`com.apple.*` 之类的二进制），被当成 JS 解析了。同类问题还有：把官方小游戏模板压缩包直接解压进 `minigame-dist/`，会多出一个 `海战/game.js`（926 字节的空白模板），同样会被一起编译。

`npm run build:minigame` 现在会自动删掉这些杂散文件，并打印 `Removed unexpected entry from minigame-dist/: xxx`。看到这行就说明目录被污染过，删完即恢复。**不要手工往 `minigame-dist/` 里放任何东西**，它是构建产物，每次构建都会被重建。

## A. 能不能起来

| 检查项 | 通过标准 | 结果 |
| --- | --- | --- |
| A1 编译无报错 | 控制台没有 `ReferenceError`、`document is not defined`、`window is not defined` | |
| A2 首屏出画面 | 看到海面、旗舰、敌舰，不是纯色或黑屏 | |
| A3 没有「启动失败」页 | 不出现「海战霸主启动失败 / 请确认设备支持 WebGL2」 | |
| A4 WebGL 版本 | 控制台确认拿到的是 WebGL2 上下文 | |

A3 出现说明 `SceneManager` 构造失败，最常见原因是 WebGL2 不可用或着色器编译失败。此时把控制台完整报错贴出来，不要凭猜改代码。

## B. 画面与 HUD

| 检查项 | 通过标准 | 结果 |
| --- | --- | --- |
| B1 3D 画面能看见 | 不是白屏、不是全黑、不是只有 HUD | |
| B2 HUD 位置正常 | 左上角船体/经验面板、右上角危险度与音效按钮都没被刘海或手势条挡住 | |

B1 出问题优先怀疑「离屏画布 → 屏幕画布」这条合成链路，也就是 `drawImage` 那一步。

## D. 局内流程

| 检查项 | 通过标准 | 结果 |
| --- | --- | --- |
| D1 击沉掉经验 | 击沉敌舰后出现经验球，靠近能自动吸附 | |
| D2 升级选卡 | 升级弹出三张卡，点哪张就生效哪张，点一次不会重复触发 | |
| D3 连续升级 | 一次拿多级时能连续选，选完自动回到战斗 | |
| D4 Boss 血条 | 约 12 秒出现「深海霸主」，顶部血条随时间下降 | |

| D7 重新起航 | 点按钮能重开，且旧炮弹、敌舰、经验球、Boss 血条都没残留 | |
| D8 反复重开 | 连续重开 5 次以上不崩、不越来越卡 | |

D7/D8 是小游戏版最容易出问题的地方：每次重开都会新建离屏 WebGL 画布，如果设备上下文有限，会在多次重开后开始掉帧或黑屏。出现这种情况先记录第几次重开开始异常。

## E. 生命周期与存储

| 检查项 | 通过标准 | 结果 |
| --- | --- | --- |
| E1 切后台 | 退出抖音再回来，游戏处于暂停而不是快进 | |
| E2 音效偏好 | 关掉音效后退出再进，仍是关闭状态 | |
| E3 音频 | 有声音，且在 Android 上第一次点屏幕后能正常出声；无声时报错信息要记录 | |

E3 说明：代码只在 `tt.createWebAudioContext` 存在时才启用声音，否则静默运行、不报错。所以「没声音但不崩」是已知降级，不是 bug；需要确认的是它有没有抛异常。

## 卡顿时可调的旋钮

先记录现象（第几分钟开始卡、什么场景卡），再动这些参数，一次只改一项：

| 想降低的负载 | 改哪里 | 说明 |
| --- | --- | --- |
| 阴影开销 | `src/game/SceneManager.ts` 中 `renderer.shadowMap.enabled` | 关掉阴影最省，画面会明显变平 |
| 分辨率 | `src/minigame/MiniGameUi.ts` 中 `pixelRatio` 的 `Math.min(..., 2)` 上限 | 降到 1 会变糊，但帧率提升明显 |
| 抗锯齿 | `src/game/SceneManager.ts` 中 `antialias` | 移动端收益通常不大，但确实费性能 |

这些改动都会同时影响网页版，改之前先确认网页版的观感可以接受。
